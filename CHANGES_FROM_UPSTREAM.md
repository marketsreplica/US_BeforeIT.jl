# Changes from upstream

US BeforeIT is an independent, U.S.-focused fork of
[bancaditalia/BeforeIT.jl](https://github.com/bancaditalia/BeforeIT.jl).

## Initial public base

- Upstream commit: `060a2060e99e106024ce3301c9572cfd44cd9092`
- Included upstream release: `v0.6.0`
- Upstream remote: `https://github.com/bancaditalia/BeforeIT.jl.git`

The complete upstream Git history is retained. MarketsReplica changes are
committed after the upstream base so that origin and authorship remain
inspectable.

## Principal additions

- U.S. 68-sector BEA calibration, validation, and versioned baseline artifacts.
- U.S. economic-outlook fitting, holdout back-testing, and forecast reporting.
- Updated Austrian structural and nowcast baselines with scenario assumptions.
- Local simulation web application and Economy Complexity Explorer.
- Additional model instrumentation, traceability, tests, and data provenance.

## Modified upstream files

Files adapted from the upstream source carry a MarketsReplica modification
notice. New files are part of this fork and are covered by the repository
license unless a file or provenance record states otherwise.

## Synchronizing

Upstream changes should be fetched from the `upstream` remote and merged into a
topic branch before they reach this fork's default branch. Conflicts should be
resolved without removing upstream copyright, license, attribution, or
authorship information.
